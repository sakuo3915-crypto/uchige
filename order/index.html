1. お申し込みの前に

制作したゲームはWeb上のURLで公開されます。URLを知らない人が閲覧する可能性もあるため、登場する人の許可を確認してください。

2. 注文者・ご希望

お手軽：通常攻撃・口癖1種類・定型エンディング

3. 主人公を設定

プレイヤーが操作するキャラクターです。主人公は1人です。

4. 敵キャラクターを設定

ゲーム途中に登場する敵です。ラスボスはここに含めません。敵をラスボスだけにしたい場合は「0人」を選んでください。

5. ラスボスを設定

ゲームの最後に登場する敵です。必ず1人設定してください。上位プランではラスボスの変身演出も追加できます。

6. エンディングメッセージ

ゲームをクリアしたときに表示するサプライズメッセージです。

7. その他・最終確認

※この試作品では情報は送信されません。確認ボタンで画面に入力内容を表示するだけです。
